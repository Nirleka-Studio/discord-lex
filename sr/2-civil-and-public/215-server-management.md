# SR 215 — Server Management Code
*(Server Management Code, SMC)*

> **Enactment Notice:** Enacted in accordance with Chapter 4 of the Server Charter (SR 100).

---

## Chapter 1: General Provisions

#### Art. 1 Definitions
In this Code:
a. *staff* means members of Administration or appointed server managers.

## Chapter 2: Specific Provisions

### Section 1: Events

#### Art. 2 Server icon
<sup>1</sup> Staff must update the Server icon for specific events, including:
a. icon for April Fool's; and
b. the default Server icon as designated by the Director.

#### Art. 3 Celebration of certain events
<sup>1</sup> Celebrating, hosting, or modifying server features based on an event is only permitted if the provisions of this article allows it.

<sup>2</sup> Permitted events include:
a. religious holidays and cultural traditions, including but not limited to:
  1. Halloween;
  2. Thanksgiving;
  3. Christmas;
  4. Eid al-Fitr;
  5. Eid al-Adha;
  6. St. Patrick's Day; and
  7. Easter.

b. celebration or events concerning workers' rights;

c. state and national holidays;

d. birthdays of current Server members; and

e. other broad, secular, familial, and popular celebrations, including but not limited to:
  1. April Fool's Day;
  2. New Year's Day;
  3. Oktoberfest; and
  4. Valentine's Day;

<sup>3</sup> Members may only add or remove events listed in paragraph 2 through a server-wide vote with a two-thirds majority.

<sup>4</sup> Server-specific events are permitted, including but not limited to:
a. gaming events; and
b. competitions.

<sup>5</sup> Events concerning an individual's personal identity or natural characteristics are prohibited.
