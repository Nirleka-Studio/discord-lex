# Drafter's Checklist

1. Check for any grammatical errors or other flaws.
2. Make sure the texts follow established style guides.
3. Bump the version law's version for modifications. `0.0.X` for typos or styles, and `0.X.0` for substantial changes. Typically 1 bump per article, change, or provision.
4. Update the `last_amended` date.
5. Build the site via `build.js`.
